# CivicBalance support files

The application source is in ../src. Run commands from the repository root.
See the [root README](../README.md) for installation, prediction, optional BERT
training, API examples, and reconstruction history.

This directory preserves the original Streamlit dashboard, SQL schema/queries,
dataset/artifact locations, and report templates. Datasets and model weights are
not committed. The templates in reports/ are not measured evaluation results.
